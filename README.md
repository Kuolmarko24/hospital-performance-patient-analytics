Hospital Performance & Patient Analytics
1. Project Overiew
This project analyzes hospital operational and financial performance using SQL Server and Power BI. The analysis focuses on patient demographics, doctor performance, appointment management, treatment analytics, revenue generation, and executive-level KPIs to support data-driven decision making.

2. Business Problem
Hospitals generate large volumes of operational data, but transforming this information into actionable insights can be challenging. This project demonstrates how SQL and Power BI can be used to analyze patient activity, doctor performance, appointments, treatments, billing, and revenue to improve operational efficiency and financial performance.

3. Project Objectives
Clean and validate healthcare datasets
Perform exploratory data analysis
Analyze patient demographics
Evaluate doctor performance
Analyze appointment efficiency
Identify revenue drivers
Develop executive KPIs
Build an interactive Power BI dashboard
